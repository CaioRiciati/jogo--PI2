# ☢️ Skelements — O poder da Tabela Periódica - Projeto Integrador II

Um jogo de ação e sobrevivência inspirado na Tabela Periódica, onde a química se transforma em poder!

##Sobre o jogo

**Elements** é um jogo de ação baseado em ondas (*waves*), no qual o jogador assume o papel de um químico que, após um experimento fracassado, acaba sendo transformado em um esqueleto.

Entretanto, o acidente desperta uma habilidade extraordinária: absorver elementos químicos e utilizar suas propriedades para desenvolver poderes.

Agora, para recuperar sua aparência humana, será necessário sobreviver a hordas de inimigos, explorar ambientes perigosos e descobrir novas combinações químicas.

## 📖 História

Um experimento químico dá errado e provoca uma reação inesperada, transformando o protagonista em um esqueleto.

Porém, o acidente também desperta uma habilidade única: absorver elementos químicos e utilizar suas propriedades.

Ao longo da jornada, o jogador precisará explorar laboratórios abandonados, fábricas e áreas contaminadas, enfrentando inimigos e descobrindo novos elementos.

A cada batalha, o protagonista ficará mais poderoso enquanto busca recuperar sua aparência original.

## ⚔️ Gameplay

O jogo possui um sistema de sobrevivência baseado em **waves**, no qual o jogador precisa enfrentar sucessivas ondas de inimigos.

Entre os principais conceitos de gameplay estão:

- **Sistema de Waves:** sobreviva a ondas progressivamente mais desafiadoras de inimigos.
- **Absorção de elementos:** descubra e utilize elementos da Tabela Periódica.
- **Poderes químicos:** cada elemento possui propriedades que influenciam as habilidades do personagem.
- **Progressão:** fique cada vez mais forte conforme avança pelas waves.
- **Exploração:** descubra ambientes, enfrente desafios e encontre novos elementos.

## 🧪 Laboratório de Combinações

Um dos principais diferenciais de Elements é o seu laboratório.

Nele, o jogador poderá combinar diferentes elementos da Tabela Periódica para criar novos poderes e habilidades.

Cada elemento possui características próprias, permitindo experimentar diferentes combinações e descobrir novas possibilidades.

A ideia é transformar conceitos da química em mecânicas de gameplay, incentivando a experimentação e a estratégia.

**Exemplos de possibilidades:**
- Combinar elementos para desenvolver novos ataques.
- Criar habilidades com efeitos especiais.
- Descobrir combinações com propriedades ofensivas e defensivas.
- Experimentar diferentes composições para encontrar estratégias mais eficientes.

## 🧬 A Tabela Periódica

A Tabela Periódica é o centro do gameplay.

Cada elemento possui propriedades que podem influenciar os poderes do protagonista. O jogador deverá escolher quais elementos utilizar de acordo com cada situação, criando combinações entre ataque, defesa, exploração e estratégia.

## 🚧 Desenvolvimento

Elements está em desenvolvimento. Novas mecânicas, elementos, combinações e desafios serão implementados ao longo do projeto.

## 🎯 Objetivo do projeto

Desenvolver um jogo que misture ação, sobrevivência e conceitos de química, utilizando a Tabela Periódica como base para um sistema de habilidades e combinações.

Mais do que sobreviver, o objetivo é descobrir até onde a química pode levar seus poderes.
